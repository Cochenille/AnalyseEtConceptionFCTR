# Activité — Le trajet d'une page Web

<div class="bg-blue-50 border border-blue-200 text-blue-900 rounded-lg p-4 mb-5">
<strong>Objectif de l'activité</strong><br>
Reconstruire, avec vos propres mots, tout ce qui doit exister pour qu'une personne voie le site d'un restaurant sur son téléphone.
</div>

## Mise en situation

Une cliente tape `bistro-exemple.ca` dans son téléphone pour consulter le menu et réserver une table.
En quelques secondes, la page s'affiche. **Que s'est-il passé entre les deux ?**

---

## Les cartes

Les cartes sont volontairement **mélangées**. Elles sont aussi disponibles sur le tableau blanc partagé de la séance.

| | Carte |
|:-:|:--|
| 🟦 | **Contenus** (textes, photos, menu, heures d'ouverture) |
| 🟦 | **Navigateur** (Chrome, Safari, Firefox…) |
| 🟦 | **Certificat SSL/TLS** (le cadenas) |
| 🟦 | **Nom de domaine** (`bistro-exemple.ca`) |
| 🟦 | **Service externe** (réservation, paiement, livraison) |
| 🟦 | **Hébergement** (le serveur où vit le site) |
| 🟦 | **Appareil** (téléphone, tablette, ordinateur) |
| 🟦 | **DNS** (l'annuaire qui traduit le nom en adresse) |
| 🟦 | **Plateforme** (WordPress, Shopify, Wix, code maison…) |
| 🟦 | **Registraire** (l'entreprise où on loue le nom de domaine) |
| 🟦 | **CDN** (réseau de serveurs qui rapproche le site des visiteurs) |
| 🟦 | **Courriel professionnel** (`info@bistro-exemple.ca`) |

---

## Consignes

### Étape 1 — Le trajet (10 min)
Placez les cartes **dans l'ordre du trajet**, de la cliente qui tape l'adresse jusqu'à la page affichée.
Reliez-les par des flèches.

<div class="bg-yellow-50 border border-yellow-200 text-yellow-900 rounded-lg p-4 mb-5">
<strong>Attention</strong><br>
Certaines cartes ne se placent pas directement sur le trajet. Mettez-les à côté et expliquez à quoi elles servent.
</div>

### Étape 2 — Qui paie quoi ? (5 min)
Pour chaque carte, indiquez :
- **qui la fournit** (une entreprise, le restaurant lui-même, la cliente…) ;
- si elle est **gratuite ou payante** ;
- si on la paie **une seule fois** ou **chaque mois / chaque année**.

### Étape 3 — Mise en commun
On compare les trajets. Là où les équipes ne sont pas d'accord, c'est souvent là que se cache une notion importante.
